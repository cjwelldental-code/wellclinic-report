# 청주웰치과 마케팅팀 업무 보고 시스템

팀 내부에서만 쓰는 업무 보고 도구입니다. 일일보고를 쌓으면 월간보고가 자동으로 채워지는 구조입니다.

설치는 [SETUP.md](./SETUP.md) 를 보세요.

---

## 화면

| 화면 | 하는 일 |
|---|---|
| 대시보드 | 오늘 보고 작성 여부, 진행 중 프로젝트, 2주 일정, 팀 최근 보고, 심의 만료 알림 |
| 일일보고 | 오늘 한 일 · 내일 계획 · 이슈 기록. 작성자 / 프로젝트 / 기간으로 조회 |
| 프로젝트 | 상태 · 담당 · 마감 · 진행률 관리. 상세 화면에 해당 프로젝트 업무 기록이 시간순으로 모임 |
| 일정 | 구글 캘린더 일정과 프로젝트 시작 · 마감을 한 달력에 겹쳐 봄 |
| 월간보고 | 한 달치 일일보고와 광고 성과를 자동 집계. 초안이 채워진 상태에서 다듬어 저장. 인쇄 · PDF 저장 가능 |
| 광고 성과 | 매체별 노출 · 클릭 · 비용 · 문의 · 예약 기록. CTR / CPC / CPA 자동 계산, 전월 대비 표시 |
| 심의 관리 | 의료광고 사전심의(의료법 제56조) 번호와 유효기간 관리. 만료 30일 전부터 경고 |
| 설정 | 연결 상태 점검, 시트 탭 생성, CSV 내려받기 |

## 구조

```
브라우저
   │
   ├─ Next.js (Vercel)          화면 + 서버 액션
   │      │
   │      ├─ 구글 스프레드시트   데이터 저장소 (탭 5개)
   │      └─ 구글 캘린더 API     일정 읽기
   │
   └─ 쿠키 세션                  팀원 선택 + 공용 비밀번호
```

데이터베이스를 따로 두지 않고 구글 스프레드시트를 저장소로 씁니다. 팀원이 시트를 직접 열어
보고 고칠 수 있고, 운영 비용이 들지 않으며, 캘린더와 같은 인증키 하나로 처리됩니다.

### 시트 탭

| 탭 | 내용 |
|---|---|
| 프로젝트 | 이름, 클라이언트, 상태, 담당자, 우선순위, 기간, 진행률, 목표, 설명, 링크 |
| 일일보고 | 날짜, 작성자, 프로젝트, 한일, 내일계획, 이슈, 소요시간 |
| 월간보고 | 연월, 작성자, 성과요약, 주요지표, 다음달계획, 이슈및제안 |
| 광고성과 | 날짜, 매체, 캠페인, 노출, 클릭, 비용, 문의, 예약, 메모 |
| 심의관리 | 소재명, 매체, 심의번호, 심의일, 만료일, 상태, 담당자, 비고 |

첫 줄은 머리글입니다. 머리글 순서를 바꾸면 데이터가 어긋나므로 열 추가는 항상 맨 뒤에만 하세요.

## 쓰는 방법

일일보고

- 하루 한 번, 퇴근 전에 씁니다. 한 줄에 한 건씩 적으면 월간보고에서 그대로 항목이 됩니다
- 같은 날 두 번 저장하면 새로 만들지 않고 기존 보고에 이어붙입니다
- 프로젝트를 골라 두면 프로젝트 상세 화면과 월간보고에서 자동으로 묶입니다

월간보고

- 월말에 열면 그달 일일보고와 광고 성과가 이미 집계돼 있습니다
- 성과 요약과 주요 지표에는 초안이 채워져 있습니다. 다듬어서 저장하세요
- 인쇄 버튼으로 원장님 보고용 PDF를 바로 만들 수 있습니다

광고 성과

- 매체 단위로 주 1회 정도 기록하면 충분합니다
- 문의 수를 넣어야 CPA가 계산됩니다. 치과는 이 숫자가 가장 중요합니다

심의 관리

- 심의 접수 시점에 심의중으로 먼저 등록해 둡니다
- 승인이 나면 심의번호와 만료일을 채웁니다
- 비심의로 집행하는 소재는 비고에 그 근거를 남깁니다

## 기술

- Next.js 15 (App Router) · React 19 · TypeScript
- Tailwind CSS v4
- googleapis (Sheets v4, Calendar v3)
- jose (세션 JWT)

폰트는 제목에 LINE Seed Sans KR, 본문에 SUIT Variable 을 씁니다. 병원 톤을 지키면서 표와 숫자가
많은 화면에서 잘 읽히는 조합입니다. 둘 다 SIL OFL 1.1 로 상업 이용과 웹폰트 임베딩이 허용됩니다.

## 주의

- 저장소는 Private 로 두세요. 서비스 계정 JSON과 .env.local 은 절대 커밋하지 않습니다
- 배포 주소와 팀 비밀번호는 팀 밖으로 공유하지 않습니다
- 환자 개인정보(이름, 연락처, 진료 내용)는 이 시스템에 넣지 않습니다. 업무 진행 상황만 기록합니다
